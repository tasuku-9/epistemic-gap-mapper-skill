# Prompt 03 — Extract Target Narratives

```text
Now identify the target narratives that my hypothesis may be challenging or reframing.

A target narrative is not necessarily a single paper. It may be a textbook story, review synthesis, disciplinary habit, or AI-frequency explanation.

For each target narrative, output:

1. Narrative Statement
   - One sentence.

2. Component Claims
   - N1, N2, N3...

3. Source Status for each component claim
   Use:
   - primary-supported
   - review-supported
   - textbook-canonical
   - synthetic consensus
   - disciplinary habit
   - AI-frequency narrative
   - untraced narrative

4. Evidence Trace
   - What papers or sources directly support it?
   - If none are found, say “direct source not identified.”

5. My Hypothesis Relationship
   - accepts / challenges / reframes / extends / does not address

6. Citation Debt
   - low / medium / high / unknown

Rules:
- A repeated story is not automatically a demonstrated conclusion.
- “No source found” is not proof that the narrative is false.
- Distinguish paper-supported claims from atmosphere or disciplinary habit.
```
