# Prompt 02 — Find Target Papers

```text
Using the central hypothesis and claim list below, identify target papers and sources.

The goal is not to collect many related papers. The goal is to identify the papers this hypothesis is actually in conversation with.

Classify target papers as:

1. Canonical Frame Papers
   - Papers or books that define the standard frame.

2. Data-Anomaly Papers
   - Papers that contain data or findings that complicate the standard frame.

3. Bridge Papers
   - Papers that may connect domains.

4. Adversarial Papers
   - Papers or sources that offer alternative explanations.

5. Primary Sources
   - Original texts, excavation reports, datasets, or primary materials.

For each candidate, provide:

- Citation candidate
- Domain
- Why it is a target paper
- What it directly supports
- What it does NOT support
- How my hypothesis extends or challenges it
- Confidence: high / medium / low
- Verification needed: yes / no

Rules:
- Do not invent citations.
- If DOI, journal, year, or publisher is uncertain, say so.
- Separate actual papers from narratives.
```
