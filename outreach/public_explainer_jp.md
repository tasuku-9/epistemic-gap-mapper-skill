# Epistemic Gap Mapper：外部向け説明文（日本語）

**Epistemic Gap Mapper** は、通説外・分野横断型の仮説を「正しい／間違い」と即断するためのツールではありません。目的は、利用者の仮説・既存論文・標準ナラティブを同じ論理地図の上に置き、どこが証拠で、どこが推論で、どこが未検証で、どこが言いすぎなのかを可視化することです。

現代の研究は高度に専門分化しています。各分野の内部では研究が進む一方で、分野をまたぐ矛盾・不足・例外は、しばしば「誰の担当でもない」問題として残ります。また、教科書・概説・AI応答の中で繰り返される標準ナラティブは、必ずしも一つの明確な論文によって直接支えられているとは限りません。Epistemic Gap Mapper は、そうした論文とナラティブのあいだにある知識の空白、すなわち epistemic gap を見える化します。

このスキルは、まず利用者の論文や仮説から主張を抽出し、次にターゲット論文とターゲットナラティブを整理します。そのうえで、Claim Node、Evidence Node、Paper Node、Narrative Node、Gap Node、Exception Node、Falsifier Node などに分解し、A/B/C/X の診断を行います。

- **A**：既存研究や公開データによって比較的強く支えられる主張
- **B**：現時点のデータと矛盾せず、仮説として提示できる主張
- **C**：まだ言い切れないが、検証可能な推測
- **X**：根拠不足、言いすぎ、または既存証拠との矛盾がある主張

この分類は、仮説を採点するためではありません。むしろ、検討可能な仮説として突破するには、どの主張をAとして足場にし、どの主張をBとして提示し、どの主張をCとして残し、どの表現をXとして修正すべきかを明確にするためのものです。

Epistemic Gap Mapper は、専門知を代替するものではありません。外部者・独立研究者・異分野からの参入者の仮説を、専門家が読める構造へ翻訳するためのものです。専門家は各ノードを検証し、どこが弱いかを具体的に指摘できます。利用者は、雑な反論や通説への自動回帰に潰されるのではなく、どの証拠・推論・ナラティブが問題なのかを明示した形で議論に入れます。

この仕組みは、AI時代に特に重要です。AIは膨大なテキストから標準ナラティブを再生産しやすい一方で、通説外の仮説を自動的に弱く扱う傾向があります。Epistemic Gap Mapper は、AIを仮説の判定者として使うのではなく、主張・証拠・ナラティブ・不足・反証条件を分離するための構造化支援として使います。

最終的な目的は、未検証だが論理構造のある仮説と、根拠不足の思いつきやAIスロップを区別することです。これは査読を置き換えるものではありません。査読前に、仮説を「検討可能な構造」へ整えるための公共的な知的インフラです。
