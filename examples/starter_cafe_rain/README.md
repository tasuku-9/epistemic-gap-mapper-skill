# Starter Example: Rainy Days and Cafe Sales

This is a deliberately small Epistemic Gap Mapper example for first-time users.

Question:

> Do rainy days increase sales at a neighborhood cafe?

The goal is not to answer the question automatically. The goal is to show how a simple everyday hypothesis can be mapped into target sources, a target narrative, evidence, risks, and falsifiers before anyone starts arguing from vibes.

Use this example before the larger Jomon / Dotaku / Kiki case.

Files:

- `nodes_starter.json` — compact node graph.
- `graph_starter.md` — readable Mermaid graph.
