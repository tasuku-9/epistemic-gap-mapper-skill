# Narrative Audit

A target narrative is not the same as a target paper.

A target paper is a specific work with explicit claims, data, authors, and limitations.

A target narrative is a diffuse standard story that may arise through textbooks, reviews, lectures, disciplinary habit, AI-frequency output, or synthesis of multiple sources.

## Narrative source status

Use the following labels:

- `primary_supported`
- `review_supported`
- `textbook_canonical`
- `synthetic_consensus`
- `disciplinary_habit`
- `ai_frequency_narrative`
- `untraced_narrative`

## Citation debt

Citation debt measures whether a standard narrative is more stable than its traceable evidence warrants.

Levels:

- `low`
- `medium`
- `high`
- `unknown`

Citation debt is **not** proof that the narrative is false. It means the root support must be clarified.

## Narrative audit output

For each target narrative, extract:

1. Narrative statement.
2. Component claims.
3. Source status.
4. Evidence trace.
5. Citation debt.
6. What the new hypothesis accepts.
7. What it challenges.
8. What it reframes.
9. Whether the conflict is about data, interpretation, integration, or habit.
